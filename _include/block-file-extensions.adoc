阻止可疑文件扩展名选项使用您为组织配置的默认列表。要link:task-file-extensions.html["使用自定义列表"]您创建的内容，请选择铅笔图标。

+ 如果您已在 ONTAP 中配置了阻止的文件扩展名列表，则可以通过选择 *使用 Ransomware Resilience 列表替换 ONTAP 列表* 来覆盖这些列表。然后选择您是希望 SVM *允许除阻止列表之外的所有文件扩展名* 还是 *阻止除允许列表之外的所有文件扩展名*。然后，从下拉菜单中选择该列表。工作负载上的所有存储虚拟机（SVM）都将使用该列表；您稍后可以将不同的列表应用于工作负载上的不同 SVM。
