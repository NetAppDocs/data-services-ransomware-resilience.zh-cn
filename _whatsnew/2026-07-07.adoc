= 从用户行为警报中排除文件路径
:allow-uri-read: 




[[exclude-file-paths-from-user-behavior-alerts]]
=== 从用户行为警报中排除文件路径

NetApp Ransomware Resilience 支持在用户行为监控警报中排除特定的文件路径。如果您知道某些文件路径不存在风险，或者正在对卷中可能触发警报的文件进行操作，则可以排除这些文件路径。

有关详细信息，请参见 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-users-manage.html["从警报中排除文件路径"^]。



[[arm-template-for-microsoft-sentinel]]
=== 适用于 Microsoft Sentinel 的 ARM 模板

Ransomware Resilience 现在提供 Azure Resource Manager (ARM) 模板，用于连接到 Microsoft Sentinel 作为 SIEM，提供辅助方法以简化部署。

有关详细信息，请参见 link:https://docs.netapp.com/us-en/data-services-ransomware-resilience/task-siem.html["连接到 SIEM 以进行威胁检测和分析"^]。
