= NetApp Ransomware Resilience 的用户活动检测要求
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Ransomware Resilience 用户行为检测使您能够对用户级别的勒索软件事件做出响应。您必须创建租户和一组代理才能启用用户行为检测。在启用检测之前，您必须确保满足概述的操作系统、服务器和网络要求，以便 Ransomware Resilience 能够正确检测和报告事件。



[[cloud-provider-support]]
== 云提供商支持

要启用用户行为检测，您必须为数据收集器创建一个可执行环境，这些数据收集器与 Ransomware Resilience 共享用户活动事件。


NOTE: 租户的区域部署对 Console 代理没有影响。Console 代理部署独立于这些区域。

可以在以下区域的 AWS 和 Azure 中部署租户：

|===
| 云提供商 | 地区 


| AWS  a| 
* 亚太地区（悉尼）（ap-southeast-2）
* 欧洲（法兰克福）(eu-central-1)
* 美国东部（弗吉尼亚北部）（us-east-1）




| Azure | 美国东部 
|===

[[server-requirements]]
== 服务器要求

服务器必须满足以下最低要求：

* CPU：4 核
* **内存**：16GB 内存
* **磁盘空间**：36 GB 可用




[[server-recommendations]]
=== 服务器建议

* 分配额外的磁盘空间以允许创建文件系统。请确保文件系统中至少有 35 GB 的可用空间。+ 如果  `/opt` 是从 NAS 存储挂载的文件夹，则本地用户必须能够访问此文件夹。如果本地用户没有必要的权限，则用户活动代理的创建可能会失败。
* 在与您的 Ransomware Resilience 环境独立的系统上安装用户活动代理。如果您确实在同一台计算机上安装了代理和 Ransomware Resilience，请预留 50 到 55 GB 的磁盘空间。对于 Linux，请为 `/opt/netapp`分配 25 到 30 GB 的空间，并为 `/var/log/netapp`分配 25 GB 的空间。
* 建议您使用网络时间协议 (NTP) 或简单网络时间协议 (SNTP) 同步ONTAP系统和用户活动代理计算机上的时间。




[[sizing-recommendations]]
=== 规模建议

收集用户事件时，请确保托管用户活动代理的计算机大小能够适应您的事件率。这意味着确保在托管用户活动代理的计算机上有足够的数据收集器和足够的 CPU 和 RAM 来处理每秒的事件数。要增加数据收集器数量，您可能需要增加 RAM 或 CPU 容量。Ransomware Resilience 每个用户活动代理最多支持 50 个数据收集器。

下表提供了尺寸调整的一般指导：

|===
| 用户活动代理机器配置 | 数据收集器数量 | 最大事件率 


| 4 核、16GB | 10 个数据收集器 | 20,000 个事件/秒 


| 4 核、32GB | 20 个数据收集器 | 20,000 个事件/秒 
|===
您还可以计算您的具体要求。在计算合适的大小时，建议您使用 30% 的缓冲率进行限定。使用此公式来确定您的配置是否可以处理负载。

[listing]
----
Where E is the sum of all events per second across all data collectors:

E + (0.3 x E) < 20,000 events/second
----
.在 Ransomware Resilience 中计算事件数据速率。
[%collapsible]
====
Ransomware Resilience 提供了一个可以在系统上运行的脚本来计算事件数据速率。默认情况下，脚本最多可运行五个 SVM。如果您的环境包含五个以上的 SVM，则可以相应地修改脚本。无论 SVM 数量多少，脚本都需要大约五分钟才能获得平均事件率读数。在运行脚本之前，您必须：

* link:suspicious-user-activity.html["已配置用户活动代理"]
* 集群 IP 地址
* 集群管理员用户名和密码
* 已在 Linux 机器上安装 `sshpass`（您可以使用命令 `sudo yum install -y sshpass`进行安装）


.步骤
. 从托管用户活动代理的计算机中，以管理员身份运行脚本： `/opt/netapp/cloudsecure/agent/install/svm_event_rate_checker.sh`
. 出现提示时，请提供集群 IP 地址、管理员用户名和管理员密码。
. 脚本运行大约需要五分钟。完成后，命令行将显示事件速率，例如"Svm svm_rate 正在生成 100 个事件/秒"。
+
使用事件率来计算您的规模。



====


[[cloud-network-access-rules]]
== 云网络访问规则

查看您所在地区（亚太地区、欧洲或美国）的云网络访问规则。


IMPORTANT: 在初始安装期间，将 `<site_name>`替换为通配符(`*`）权限。激活代理并完全运行后，您可以将权限替换为站点名称。有关站点名称，请联系您的 NetApp 代表。


NOTE: 用户活动代理使用 NetApp Data Infrastructure Insights 技术，因此使用  `cloudinsights` 端点。有关详细信息，请参见 link:concept-user-behavior.html#user-activity-forensics["Ransomware Resilience 和 Data Infrastructure Insights"]。
